# Neon Snake Game

A sleek, premium, web-based version of the classic Snake game. It features dynamic speed scaling (gets faster as you eat!), sound effects generated via the Web Audio API, and a beautiful neon cyber aesthetic.

## Features
- **Modern Design**: Dark mode aesthetic with neon glowing elements and Google Fonts typography.
- **Dynamic Speed**: The game starts at a moderate pace but gradually gets faster as your score increases.
- **Synthesized Audio**: Procedurally generated sound effects for eating and Game Over without external assets.
- **Robust Mechanics**: Queue-based input handling eliminates classic bugs (like dying by turning onto yourself in a single frame).

## How to Play
1. **Launch the Game**: Simply double-click the `index.html` file to open it in your default web browser. No server setup is required!
2. **Setup Audio**: Click anywhere on the screen or press an arrow key first to initialize the browser's audio engine.
3. **Controls**: Use the **Up**, **Down**, **Left**, and **Right Arrow Keys** to move the snake.
4. **Goal**: Eat the glowing pink food to increase your score and grow longer.
5. **Rules**: Do NOT hit the walls or your own tail, or it's Game Over!

Enjoy!
